# Observability and flow

Observe the application and the engineering system.

## Application signals

Measure when relevant:

- errors, latency, availability, and performance;
- accessibility;
- user outcomes;
- privacy events without exposing personal data.

## Engineering-flow signals

Measure when relevant:

- intent-to-merge and merge-to-production time;
- change size and frequency;
- gate failures and rework;
- defects before and after deployment;
- agent cost, usage, and human intervention;
- time to verified value.

Do not use lines of code as a value metric. Optimize for useful, verified change.
