# Definition of done

A feature is not done because an agent says it is done.

A feature is done only when:

- acceptance criteria are demonstrated;
- relevant tests pass;
- mandatory gates pass;
- security and privacy impact is assessed;
- architectural boundaries remain valid;
- the diff is reviewed;
- required documentation is updated;
- the change is deployable;
- observable outcome evidence exists;
- a human approves integration.
