# Accessibility

**Target: WCAG 2.1, level AA.** Set by the human on 2026-08-11, resolving spec
`O5`. Before that the position was "the automated checks pass", which is not a
conformance claim and was recorded as such.

This document exists because setting a target changes what has to be true. It
records what the target already covers, what it newly obliges, and — the part
that matters — which criteria nobody has checked.

## What the automated scan does and does not cover

axe-core 4.13 runs over eight interface states with the tags `wcag2a`,
`wcag2aa`, `wcag21a`, `wcag21aa`: **69 of its 105 rules**. Of the 36 excluded, 30 are
`best-practice` — not WCAG criteria at all, and excluded deliberately so a
failure means a conformance failure. Three are `wcag2aaa`. The remaining three
are `duplicate-id` and `duplicate-id-active`, which axe marks deprecated because
WCAG 2.1 removed the criterion they served, and `target-size`, which is a WCAG
2.2 criterion and therefore outside this target. **No level A or AA rule of
WCAG 2.1 is skipped.**

**Passing that scan is not conformance to AA.** Automated tooling detects on the
order of a third of real accessibility defects. It cannot judge whether a label
makes sense to someone who cannot see the screen, whether reading order is
logical, or whether alternative text describes the right thing. Every focus
defect this project shipped and later fixed passed the axe scan cleanly and was
caught by a hand-written keyboard assertion or by review.

## What is not met

Four things, stated rather than implied:

1. **No screen-reader testing has been done**, by anyone. The ARIA is
   structurally correct as far as code review goes; nobody has listened to it.
2. **1.4.4 (Resize Text), 1.4.11 (Non-text Contrast), and 1.4.12 (Text
   Spacing) are unverified.** All three are AA and all three are checkable —
   they are simply not checked yet.
3. **No audit by an accessibility practitioner.** The table above was written by
   the agent that wrote the code, which is the weakest possible reviewer of it.
4. **No conformance claim is published.** The README does not assert AA
   conformance and should not until at least the three unverified criteria are
   closed and someone other than this agent has looked.

**Accepted as it stands on 2026-08-12.** The human read the four items above
and chose to leave them. That is a decision, not an oversight, and it is
recorded here rather than in a conversation — but it does not make the state
different: three AA criteria are still unverified and nobody has listened to
this with a screen reader.

The target is set. Meeting it is not the same as having set it, and this
document exists so the difference stays visible.
